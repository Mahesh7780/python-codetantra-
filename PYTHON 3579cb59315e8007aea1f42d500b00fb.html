Variables :-


A variable is essentially a name that is assigned to a value.Variables are used to store information and manipulated during program execution.

  • Unlike other languages, Python variables do not require explicit declaration of type.
  • The variable type is automatically decided based on the value given to it.

Example :

x = 5
name = "Alex"  
print(x) #5
print(name) #Alex

Rules for Naming Variables ( Naming convention ) :-

  1. Variable names can only contain letters, digits and underscores (_).
  1. A variable name cannot start with a digit.
  1. Variable names are case-sensitive like myVar and myvar are different.
  1. Avoid using Keywords like if, else, for as variable names.
# Valid ✔
age = 21
_colour = "lilac"
total_score = 90

#Invalid ❌
1name = "Error"  # Starts with a digit
class = 10       # 'class' is a reserved keyword
user-name = "Doe"  # Contains a hyphen

Assigning Values to Variables

Basic Assignment: Variables are assigned values using the = operator.

x = 5
y = 3.14
z = "Hi"

Dynamic Typing: variables are dynamically typed, meaning the same variable can hold different types of values during execution.

x = 10
x = "Now a string"

Multiple Assignments

Assigning Same Value: allows assigning the same value to multiple variables in a single line, which can be useful for initializing variables with the same value.

a = b = c = 100
print(a, b, c)  #100 100 100

Assigning Different Values: we can assign different values to multiple variables simultaneously, making the code concise and easier to read.

x, y, z = 1, 2.5, "Python"
print(x, y, z) #1 2.5 Python

Variable Reassignment :

we check whether modifying one variable affects another when both initially reference the same object.

x = 1
y = x
y = y + 1

print(x) #1
print(y) #2

Type and Casting a Variable :
• Type casting means converting the value of one data type into another. Python provides several built-in functions to facilitate casting, including int(), float() and str() among others.

  • Type of a variable can be determine using type(). function which returns the type of the object passed to it.
x = 10          # int
y = 3.5         # float
name = "John"   # string
is_ok = True    # boolean

print(type(x)) #<class 'int'>
print(type(y)) #<class 'float'>
print(type(name)) #<class 'str'>
print(type(is_ok)) #<class 'bool'>

Deleting a Variable

We can remove a variable from the namespace using the del keyword. This deletes the variable and frees up the memory it was using

x = 10
del x
print(x)  #ERROR!

Practical Examples :

1. Swapping Two Variables: Using multiple assignments, we can swap the values of two variables without needing a temporary variable.

a, b = 5, 10
a, b = b, a
print(a, b) #10 5

2. Counting Characters in a String: Assign the results of multiple operations on a string to variables in one line.

word = "Python"
length = len(word)
print("Length of the word:", length) #Length of the word: 6

Data types in Python are a way to classify data items. They represent the kind of value which determines what operations can be performed on that data. Since everything is an object in Python programming, Python data types are classes and variables are instances (objects) of these classes.

built-in data types in Python :

  • Numeric: int, float, complex
  • Sequence Type: string, list, tuple
  • Mapping Type: dict
  • Boolean: bool
  • Set Type: set, frozenset
  • Binary Types: bytes, bytearray, memoryview

Working of Built-in Functions and Their Internal Working

Built-in functions like type(), id(), print(), and len() are implemented in C (in CPython) for performance.

  • type(obj): Returns the class of the object. Internally, it accesses the ob_type pointer in the C structure of the object.
  • id(obj): Returns the unique identifier of an object, which in CPython is the memory address of the object.
  • len(obj): Calls the __len__() dunder method of the object. For built-in types like lists and strings, it directly reads the size field from the C struct, which is an O(1) operation.

Memory Management and Interning: Python uses reference counting and a garbage collector. For performance, Python caches small integers (from -5 to 256) and interns certain strings (like identifiers). This means multiple variables assigned the value 10 will point to the exact same memory address.

Lists

A list is an ordered, mutable collection of items. It can contain elements of different data types. Internally, lists are dynamic arrays. When a list grows beyond its current allocated capacity, Python over-allocates memory to allow for O(1) amortized appends.

my_list = [1, 'Python', 3.14, True]
print(my_list)

# Modifying a list
my_list[0] = 100
my_list.append('New Item')
print(my_list)

Tuples

A tuple is an ordered, immutable collection. Once created, its elements cannot be modified. They are more memory efficient than lists and can be used as dictionary keys if all their elements are immutable.

my_tuple = (1, 2, 3, 'Python')
print(my_tuple)

# Accessing elements
print(my_tuple[1])

# my_tuple[0] = 10 # This would raise a TypeError

Strings

A string is a sequence of characters. In Python 3, all strings are Unicode. Strings are immutable, meaning any operation that modifies a string actually creates a new string object.

my_string = 'Hello, Python!'
print(my_string)
print('Length:', len(my_string))
print('Uppercase:', my_string.upper())

Frozen Sets

A frozenset is an immutable version of a set. A set is an unordered collection of unique elements. Because a frozenset is immutable, it is hashable and can be used as a dictionary key or an element of another set.

normal_set = {1, 2, 3, 3}
frozen = frozenset([1, 2, 3, 4, 4])

print('Set:', normal_set)
print('Frozenset:', frozen)

# normal_set.add(5) # Valid
# frozen.add(5) # AttributeError: 'frozenset' object has no attribute 'add'

Dictionaries

A dictionary is an unordered (ordered by insertion in Python 3.7+), mutable collection of key-value pairs. Keys must be immutable and hashable (like strings, numbers, or tuples). Internally, dictionaries are implemented as highly optimized hash tables.

my_dict = {'name': 'John', 'age': 25, 'language': 'Python'}
print(my_dict)

# Accessing and adding elements
print('Name:', my_dict['name'])
my_dict['city'] = 'New York'
print(my_dict)

Bytes

The bytes type represents an immutable sequence of bytes (integers in the range 0 <= x < 256). It is useful for binary data like images, network packets, etc.

`b_data = b'Hello'
print(b_data)
print('First byte:', b_data[0]) # Returns ASCII value of 'H'

# b_data[0] = 65 # TypeError: 'bytes' object does not support item assignment`

`b'Hello'
First byte: 72`

Byte Arrays

The bytearray type is a mutable counterpart to bytes. It allows modification of the bytes in-place.

ba_data = bytearray(b'Hello')
print(ba_data)

# Modifying a bytearray
ba_data[0] = 74 # ASCII for 'J'
print(ba_data) # Output: bytearray(b'Jello')
